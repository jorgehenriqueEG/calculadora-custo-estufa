# calculadora-custo-estufa

## Descrição do Problema

Um produtor de orquídeas precisa estimar o custo mensal de energia para manter a estufa aquecida. O cálculo depende da potência do aquecedor, das horas de funcionamento diário e do preço da energia.

## Requisitos

- Receber potência em watts, horas diárias e preço por kWh.
- Calcular o consumo mensal em kWh considerando 30 dias.
- Aplicar um desconto de 10% para pagamento até o vencimento.

## Exemplo de Uso

Entrada: potência=2000, horas=8, preco=0.90

Saída: R$ 43.20
